# 🧠 Портфолио проектов по аналитике данных

## 🔍 Краткий обзор

| Проект | Задача | Ключевые инсайты | Стек |
|--------|--------|---------------------------|------|
| **🏨 Отмены бронирований отелей** | Выявить факторы отмен и предложить меры | 37% отмен, пик летом у City Hotel до 60%, аномалия в августе 2016, lead time → риск | `pandas` `seaborn` `plotly` `scipy` |
| **👥 HR-аналитика текучести** | Диагностика причин оттока и удержания | Текучесть 33.4%, в Production 39.7%, менеджеры с >54%, зарплатный разрыв 60% | `pandas` `matplotlib` `seaborn` `scipy` |
| **📱 Такси: сезонность и пунктуальность** | Сезонность заказов, оценки водителей, ошибки платформы | 20 водителей → 65% превышений времени, рейтинг 3.9 vs 4.6, пик заказов осенью | `pandas` `seaborn` `DataLens` |
| **🎮 Игровой сервис: удержание и успех** | Анализ success rate, премиум, платформ, удержания | Success rate 73.1%, 97.6% одноразовых пользователей, разница групп 18-24 и 35-49 статистически значима | `pandas` `seaborn` `scipy` |
